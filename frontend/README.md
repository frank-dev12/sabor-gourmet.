# Sabor Gourmet — Frontend

Interfaz web (Next.js 16, TypeScript, Tailwind CSS 4) para el sistema del restaurante Sabor Gourmet.

```bash
npm install
npm run dev   # http://localhost:3000
```

Requiere el backend corriendo en `http://localhost:8080/api` (configurable con `NEXT_PUBLIC_API_URL`, ver `.env.example`).

La documentación completa del proyecto (arquitectura, API, reglas de negocio y solución de problemas) está en el [README principal](../README.md).
